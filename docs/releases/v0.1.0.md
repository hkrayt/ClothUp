## ClothUp v0.1.0 — Foundations

The first build of ClothUp (لبسني). It sets up the app on every platform and introduces the design system; it doesn't suggest outfits yet.

- Clean light and dark themes that follow your system, or set them manually
- English and Arabic with full right-to-left layout
- App icon, splash screen and Arabic app name on Android
- Builds for Android, Windows, macOS and Linux
